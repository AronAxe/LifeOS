# HALOS on Hermes — project-context reference

This file is **reference material** for a principal who deliberately wants HALOS guidance in a specific Hermes project. The importer does not copy it into a project, and it must not be treated as an automatic global constitution.

If the principal approves a project-context change, create or amend that project’s `HERMES.md` or `.hermes.md` according to Hermes’s documented project-context rules. Keep it concise and project-specific.

- **TELOS:** principal-supplied configured source; never a hard-coded personal path.
- **Skills:** imported into `$HERMES_HOME/skills/` by `LifeOS/Tools/ImportSkills.ts`.
- **Memory:** configured Hindsight for durable knowledge, entities, and relationships.
- **Cognitive graph:** optional, principal-controlled decision architecture for reviewed values, heuristics, tensions, mental models, and projects.
- **Plugin:** optional `lifeos` plugin with explicit tools and passive evidence hooks; no identity, policy, constitution, or automatic workflow injection.

The HALOS constitution is doctrinal reference material. Hermes has no public `ephemeral_system_prompt` installation path. Do not claim that this file or the constitution is automatically loaded.
