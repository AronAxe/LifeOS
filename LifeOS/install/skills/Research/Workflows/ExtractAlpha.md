# Extract Alpha Workflow

Use this workflow to identify non-obvious, decision-relevant findings from a bounded source set. “Interesting” is not a decision criterion, and ordinary summaries are not alpha.

## 1. Frame the decision

State the decision, current consensus/base case, time horizon, and what evidence would materially change the action. Define exclusions and the minimum evidence standard before extraction.

## 2. Build the evidence set

Retrieve the strongest primary sources and a small number of high-quality secondary interpretations. For each source keep a receipt with URL/path, date, publisher, exact locator, and extraction limitation. Save working notes in the current task workspace; do not depend on a hidden history tree.

## 3. Generate candidate findings

For every candidate capture:

```text
id: A1
finding: concise non-obvious claim
consensus_or_baseline: what this differs from
evidence: quote/data plus exact locator
source_ids: [...]
mechanism: why the evidence implies the finding
alternative_explanations: [...]
disconfirming_evidence: [...]
decision_implication: what changes if true
```

Separate source fact, inference, and speculation. Quantify where the source permits it; do not manufacture precision.

## 4. Challenge pass

Search specifically for the strongest conventional explanation, contradictory data, selection effects, stale information, survivorship bias, and incentives of the source. Merge duplicates. Reject findings whose novelty comes only from unfamiliar wording or whose implication does not survive a plausible alternative explanation.

## 5. Score and rank

Score each surviving item on a documented 1–5 scale:

- evidence strength;
- novelty relative to the defined baseline;
- decision impact;
- robustness to alternatives;
- time sensitivity.

Record confidence separately from impact. A high-impact fragile hypothesis must remain visibly fragile.

## 6. Output

Deliver:

1. decision and baseline;
2. source/evidence coverage;
3. ranked findings;
4. rejected candidates and why;
5. contradictions/unknowns;
6. next evidence that would most reduce uncertainty.

Each finding must include evidence, alternative explanation, confidence, decision implication, and source links. Verify every citation and numeric claim before delivery.
