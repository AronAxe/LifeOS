# Upstream LifeOS Documentation Archive

This tree preserves public source-system documentation for capability comparison and adaptation work.

It is **not** the HALOS-on-Hermes installation contract. Statements here about Claude Code hooks, `CLAUDE.md` imports, session-start loading, Pulse, launchd, automatic memory capture, private `USER/` trees, or generated settings describe upstream LifeOS unless a verified HALOS adapter says otherwise.

For the supported release surface, use:

- `LifeOS/INSTALL.md` — canonical consent-gated installation guide;
- `LifeOS/install/HERMES.md` — Hermes adaptation boundary;
- `PORT_SCHEMAS/hook_mapping.md` — evidence-based capability/hook ledger;
- `LifeOS/install/plugins/lifeos/` — optional plugin implementation.

Importing HALOS does not activate behavior described only in this archive.
